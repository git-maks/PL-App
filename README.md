# UniQuest — Politechnika Lubelska

Progressive Web App, która podczas wydarzeń na kampusie Politechniki Lubelskiej buduje profil kompetencyjny
uczestnika w formie karty postaci RPG i rekomenduje kierunki studiów oraz koła naukowe.

- [Brief](Brief%20Aplikacja.md)
- [Specyfikacja techniczna i decyzje](docs/SPECYFIKACJA.md)
- [Baza wiedzy o PL (źródła)](docs/BAZA_WIEDZY.md)

Stack: SvelteKit + TypeScript (PWA) · Go · PostgreSQL · Docker.
